# chain-reg-ts
Cosmos Chain Registry with Typescript


### Purpose

This repository uses typescript to define types to act as a tool to fetch and derive data from the [Cosmos Chain Registry](https://github.com/cosmos/chain-registry).


### Setup

The recommended setup is to add both this repository and the Cosmos Chain Registry as a submoldule to the parect directory.

If using this repo as a submodule, it is recommended to NOT modify the submodule.
Instead, update the /src/config.ts file.
