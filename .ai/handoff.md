The core refactor is largely complete. Discovery now produces a tree of DiscoveryResults containing discovered values and child discoveries. Import mappings also form a tree, with expression-based source selection replacing the old ImportSource hierarchy. The remaining work is primarily architectural refinement rather than refactoring. The main design question is to simplify ImportMapping semantics: accepts should likely exist only on root mappings to establish where an import subtree begins, while child mappings should derive their discovery context from their parent and use only source to select structured data. Likewise, importing without an explicit source should probably contribute only computed fields rather than flattening the current discovery value automatically. After those semantics are finalized, the remaining work includes inferring accepts where possible, restoring inferred child mappings, refining identity pruning, and polishing the expression DSL. The importer is now functional, with merged rows working correctly, so the focus should shift from correctness to simplifying and clarifying the model.
